- A native library is now loaded after only the libraries it needs, which a new `needs` line of the natives' `manifest.txt` names, and each library under a lock of its own, so that a window's thread loads SDL while the thread that makes the GPU device loads wgpu-native. The natives modules declare that none of their libraries needs another. A manifest without `needs` lines, as in a folder given with `rethinkj.ui.natives.dir`, still loads every library listed before the one asked for.
